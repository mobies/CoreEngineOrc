# Core Engine Orchestrator - Project Context

## 🎯 Project Vision
Membangun Multi-Agent AI Orchestrator yang cerdas, multiflatform, dan mandiri dalam mengelola proyek pengembangan aplikasi tingkat lanjut.

## ⚠️ CRITICAL RULES FOR AI AGENTS (MANDATORY)
Instruksi di bawah ini WAJIB dipatuhi oleh AI mana pun yang berinteraksi dengan repositori ini:

1. **NO UNCOMMANDED DELETION:** Jangan pernah menghapus fungsi, fitur, atau blok kode yang sudah ada tanpa perintah eksplisit dari USER.
2. **CHECK BEFORE CHANGE:** Selalu baca isi file secara utuh sebelum melakukan modifikasi. Pastikan logika baru tidak merusak logika lama.
3. **DOCUMENTATION INTEGRITY:** Jangan menghapus komentar atau dokumentasi teknis yang sudah ada.
4. **INCREMENTAL IMPROVEMENT:** Lebih baik menambah (add) atau memperbaiki (fix) daripada mengganti total (replace), kecuali diminta untuk refactoring.
5. **SYNC AWARENESS:** Selalu pastikan status terakhir tersinkronisasi dengan `docs/brain/latest_plan.json` dan Git.
